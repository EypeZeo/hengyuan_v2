# docs 交互视图生成器

将 `docs/HengYuan_v2_全自动量化实盘系统实施指南与TODOLIST.md` 渲染为单文件、离线自包含的
交互式 HTML。**Markdown 是唯一权威副本**，本目录全部产物由脚本推导，不含手工录入数据。

## 命令

```powershell
python tools/doc_site/build_site.py           # 生成 docs/HengYuan_v2_...TODOLIST.html
python tools/doc_site/verify_site.py          # 43 项结构与一致性校验，失败退出码 1
python tools/doc_site/verify_gates.py         # 19 项闸门负向对照：确认每项校验都真的会失败
node   tools/doc_site/verify_interaction.mjs  # 66 项交互行为回归（真实浏览器 + 真实鼠标）
node   tools/doc_site/verify_nojs.mjs         # 10 项无 JavaScript 降级核对
node   tools/doc_site/snapshot_states.mjs     # 截取关键界面状态，供人工核对视觉
python tools/doc_site/snapshot_panels.py      # 抽出代表性面板为独立调试页
```

生成与校验只依赖 Python 3 标准库；交互回归与截图依赖 Node（内置 `WebSocket`）与本机
Chrome/Edge，均不引入 npm 依赖。产物不产生任何外部请求。

## 为什么校验分四层

单层校验曾给出过完全错误的结论：生成物中有过一处多余的右括号使**整段脚本无法解析**，
页面上主题切换、动画暂停、悬浮摘要、检索、筛选全部静默失效，而当时的结构校验 26 项
依旧全绿——因为它只读 HTML 文本，从不执行脚本。此后校验拆成四层，各自负责一类失败：
| 层 | 能发现 | 发现不了 |
| :--- | :--- | :--- |
| `verify_site.py` | 结构、锚点、同源一致性、脚本语法、主题变量完整性、挂载点缺失 | 行为是否正确 |
| `verify_gates.py` | 闸门本身是否空转（对产物注入缺陷，确认校验会失败） | — |
| `verify_interaction.mjs` | 真实行为：跳转落点、暂停是否真停、防抖时序、主题对比度 | 视觉是否好看 |
| `verify_nojs.mjs` | 关掉脚本后是否仍完整可读 | — |

`verify_gates.py` 的存在理由：一条从不失败的闸门等于没有闸门。它为每个闸门注入它本该
捕获的那一类缺陷（多一个右括号、双百分号长度、清空浅色主题块、移除挂载点……），断言
判定函数确实报失败。它与主校验共用同一份判定实现（`verify_site.py` 中的模块级函数），
不存在两套逻辑各自演化的空间。

## 交互设计要点

| 区块 | 交互 |
| :--- | :--- |
| 技术路线站点图 | 列车位置等于该线路已达进度；脉冲环为进行中站点；虚线旋转环为下一个可开工站点 |
| 悬浮摘要 | 延迟 140 ms 出现，结构化展示状态、线路、负责人、预期完成、依赖、预估、所属章节；同一站点内部移动不重触发，故无闪烁 |
| 单击站点 | 默认跳转到该站点**所属章节标题**并高亮；可切换为「定位卡片」；<kbd>Alt</kbd> 单击临时取反 |
| 进行中站点 | 单击时动画停顿，站点显示锁定环；停顿到期后若站点图不在视口内则保持，回到图上才恢复 |
| 暂停动画 | 同时停 CSS 动画与 SMIL 列车（`animation-play-state` 管不到 `animateMotion`，必须调 `pauseAnimations()`）；站点图滚出视口自动暂停 |
| 检索 | 0.3 秒防抖；同时收敛站点图、时间轴、站点卡片、故障注册表与任务卡片；命中处 `<mark>` 高亮 |
| 筛选 | 分面计数随当前查询实时更新；计数为 0 且未选中的片自动禁用；无结果给出空状态与一键清除 |
| 主题 | 浅色/深色各自持有完整变量集（含线路色、描边色、装饰色、阴影）；首帧前落定，无闪屏；跟随系统偏好 |
| 全局 | 阅读进度条、回到顶部、目录滚动跟随、锚点跳转避开吸顶栏、快捷键 <kbd>/</kbd> <kbd>Esc</kbd> <kbd>P</kbd> <kbd>T</kbd> <kbd>?</kbd>（字母键大小写均可，匹配时统一转小写；按钮以 `aria-keyshortcuts` 声明） |

约束：无 JavaScript 时页面仍完整可读，脚本只做增强；`prefers-reduced-motion` 下动画默认停止；
打印样式隐藏交互控件、展开被筛掉的内容并避免卡片跨页断开。
写入 `localStorage` 的只有主题、动画开关、单击行为与快捷键行展开状态，不联网、不外发。

## 权威性与防漂移

生成器从 Markdown 解析站点、故障用例、任务、附录与全部标题锚点，不重命名、不重排、
不新增章节标题，只在既有无标题位置插入展示型面板。因此交互视图与 Markdown 的锚点集合
逐字符一致，`verify_site.py` 会逐项比对并在任何一项不一致时以非零退出码失败。

`D11` 校验尤为关键：它交叉核对 `1.2` 线路总览的类名、节点内联标记与 `1.3` 明细表的状态列。
该检查上线时即发现 A0 站点在总览中为已完工、在明细表中为待实现，且其节点内联标记自相矛盾。

`J6`/`J7` 是同一类"标示与行为必须一致"的检查：快捷键行把字母键写成大写 `<kbd>P</kbd>`
`<kbd>T</kbd>`，脚本就必须以大小写无关的方式匹配 `e.key`——否则界面上标着 <kbd>P</kbd>，
用户按 Shift+P 得到的 `'P'` 却不匹配只比对 `'p'` 的分支，标示反而成了误导。二者拆成两条
闸门，分别断言标示形态与匹配实现，`verify_gates.py` 对两条都注入了反向缺陷。

## 更新协议

任何一次主干合并或站点状态变更后：

1. 先改 Markdown（权威副本），并同步 `卷 1` 站点图、站点明细、所属章节与 `附录 B` 变更日志；
2. 运行 `build_site.py` 重新生成 HTML；
3. 依次运行 `verify_site.py`、`verify_gates.py`、`verify_interaction.mjs`、`verify_nojs.mjs`，
   必须全项通过后再提交；
4. Markdown 与 HTML 在同一次提交内一并更新，禁止只改其中之一。

## 实现要点

- Mermaid 子集（`graph LR/TD`、`subgraph`、`A(["标签"])`、`A["标签"]`、`-->`、`-.->`）由内置
  布局器转为 SVG；分层用最长路径，层内用重心法做双向扫描以减少连线交叉；有 `subgraph`
  时按泳道排布。
- LaTeX 子集（`\text`、`\frac`、上下标、常用符号）转为原生 MathML，离线渲染，无 KaTeX/MathJax。
- 原始的 HTML 注释标注在 `附录 E.3` 的代码围栏内逐行保留并转义，既不被渲染管线显示，
  又可被脚本按行解析。
- 线路配色只由 CSS 变量 `--lane-a..--lane-e` 持有，生成端仅输出 `lane-A..lane-E` 类名，
  避免颜色出现两处真值源。
- 站点检索文本、元素清单在初始化时各建一次（`el.__q`），检索时不再重复查询 DOM；
  命中高亮只处理文本节点，先撤旧标记再打新标记，并在无查询时完全跳过。
