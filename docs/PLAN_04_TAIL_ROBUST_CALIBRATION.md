# PLAN-04 两项覆盖偏差的有向秩修正与独立验证

## 预先固定的方案

此前独立验证结果为 `not_calibrated`。独立正态 14 日的合并 Wilson 区间上界为 98.57%，高于 98%。正自相关混合差异 7 日的区间下界为 91.85%，低于 92%。本轮针对这两个情景和长度校准。 [上一轮独立验证](PLAN_04_TAIL_HELDOUT_CALIBRATION.md)

1. 沿用上一轮设计种子 `20261201`、四个生成情景、365 日、12 对、7/14/28 日期望区块长度、每个长度 4,999 次抽样以及 `0.925, 0.930, …, 0.985` 的秩网格。先调用既有的 `select_levels()` 得到上一轮选定秩，设计样本之外的信息不参与选择。
2. 只对两个已登记单元做有向修正：
   - `gaussian_null` 的 14 日区块只允许**下调**秩（缩窄区间，减少过覆盖）；其他情景的该长度保持上一轮选定秩。
   - `ar_mixed_alternative` 的 7 日区块只允许**上调**秩（加宽区间，减少欠覆盖）；其他情景的该长度保持上一轮选定秩。
   各自选择与 95.5% 目标覆盖率绝对偏差最小的秩。对于 `N` 次重复中覆盖 `C` 次的候选，比较整数距离 `|1000 × C − 955 × N|`。距离相同时，过覆盖情景取较低秩，欠覆盖情景取较高秩。上一轮选定的主情景约束仍须满足。
3. 选定后冻结，使用两颗**新的**独立种子 `20261204`、`20261205`，每颗每情景 400 次重复。不得根据这两颗种子的结果回头修改秩；若需再改方案，必须另起实验并使用新的独立种子。

## 判定标准

- 合并数据按上一轮标准：每个情景、每个长度的同时覆盖率，其逐项 95% Wilson 区间整体位于 92% 至 98%；每个长度及三种长度一致判定的误报率，其逐项 95% Wilson 区间上界不超过 7.5%。
- 每颗验证种子分别用点估计检查同样的覆盖率和误报率容差，两颗均须通过。
- 主情景 `ar_positive_null` 的配对覆盖改善标准沿用上一轮：原秩与本轮新秩比较，净增至少 1.00 个百分点，且不一致结果中新秩覆盖占比的 Wilson 下界超过 50%。
- 设计约束、任一验证标准未满足，或任一估计失败时，状态为 `not_calibrated`。Smoke 只验证流程，不用于宣称校准通过。

## 流程验证

定向测试覆盖原始覆盖次数的选秩、并列处理、输入校验和独立种子隔离，共 9 项通过。每个种子每情景 4 次重复、每个长度 199 次抽样的小规模验证中，单进程与双进程生成的 JSON 一致。完整 Python 回归 1,151 项通过、2 项跳过，Ruff 检查通过。

## 正式验证结果

设计种子 `20261201` 完成 1,200 次重复，验证种子 `20261204`、`20261205` 共完成 3,200 次独立重复，五种方法均无估计失败。独立正态 14 日选定水平仍为 0.965，设计覆盖为 286/300。正自相关混合差异 7 日选定水平为 0.975，对应第 4,875 项，设计覆盖为 288/300。其余情景和长度沿用预先选定的水平。
