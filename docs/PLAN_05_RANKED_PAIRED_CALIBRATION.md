# PLAN-05 配对区间的外侧秩校准

## 预先固定的方案

延用 AR(1) 预白化、Bartlett 带宽 8、期望区块长度 16 和 399 次重采样。对升序排列的 `B` 个学生化枢轴，使用 `k/(B+1)` 作为第 `k` 项的概率位置。双侧区间取秩 `floor((B+1)α/2)` 和 `B+1−floor((B+1)α/2)`，单侧下限使用上侧秩 `B+1−floor((B+1)α)`。秩从 1 起算。对于 `B=399`、`α=0.05`，三个秩分别为 10、390 和 380。这样直接使用尾部观测值，并向外舍入不可整除的秩。抽样数无法提供有限尾部秩时记录估计失败。 [样本分位数与概率位置](https://robjhyndman.com/papers/sample_quantiles.pdf) · [上一轮预白化区间](PLAN_05_PREWHITENED_PAIRED_CALIBRATION.md)

独立种子固定为 `20261124`。沿用四个情景，每个情景 512 期、同期配对相关 0.6、边际标准差 1%，各重复 6,000 次。主情景为 AR(1) 系数 0.5 且真实均值差为零。其他情景为独立正态零优势、厚尾零优势和 AR(1) 系数 0.5 且真实均值差 0.001。基本区间、线性插值预白化区间和外侧秩预白化区间共用数据及索引。线性插值预白化区间作为同次对照，正式判定比较外侧秩区间与基本区间。

## 判定标准

- 四个情景的双侧 95% 覆盖率须以逐项 95% Wilson 区间整体落入 92%–98%。
- 三个零优势情景的单侧 5% 误报率须以逐项 95% Wilson 区间上界不超过 7.5%。非零均值差情景的功效和平均区间宽度用于描述。
- 主情景相对同次基本区间的覆盖率点估计须净增至少 2 个百分点。在两种方法覆盖结果不一致的重复中，外侧秩区间覆盖占比的 95% Wilson 区间下界须高于 50%。
- 任一估计失败或任一必需条件未满足时，总状态为 `not_calibrated`。

## 复现命令

从仓库根目录运行。JSON 报告同时列出基本区间、线性插值预白化区间和外侧秩预白化区间的覆盖计数、拒绝计数及平均宽度。`--smoke` 用于检查命令入口。

```powershell
python -B -m py_core.tools.calibrate_paired_studentized --rank-quantiles
```

## 独立验证结果

2026-11-18 使用 NumPy 2.5.1 完成 24,000 次模拟，三种方法各有 24,000 个有效估计。总状态为 **`within_tolerance`**。

| 情景 | 基本区间覆盖率 | 线性预白化覆盖率 | 外侧秩预白化覆盖率与 Wilson 区间 | 外侧秩单侧拒绝率与 Wilson 区间 |
| --- | ---: | ---: | --- | --- |
| 独立正态，零优势 | 92.98% | 93.40% | 93.83% [93.20%, 94.41%] | 5.88% [5.32%, 6.51%] |
| 正相关，零优势 | 91.57% | 93.37% | 93.92% [93.28%, 94.49%] | 5.97% [5.40%, 6.59%] |
| 厚尾，零优势 | 92.87% | 93.02% | 93.63% [92.99%, 94.22%] | 5.70% [5.14%, 6.32%] |
| 正相关，真实均值差 0.001 | 91.83% | 93.72% | 94.20% [93.58%, 94.76%] | 43.67% [42.42%, 44.93%] |

主情景相对于基本区间净增 141 次覆盖，即 2.35 个百分点，超过预设的 120 次。141 次覆盖结果不一致的重复均由外侧秩区间覆盖，占比的 95% Wilson 区间为 [97.35%, 100.00%]。同次线性预白化对照的覆盖率为 93.37%，外侧秩使其再增加 0.55 个百分点。三个零优势情景的误报率上界均低于 7.5%。

| 情景 | 基本区间平均宽度 | 线性预白化平均宽度 | 外侧秩预白化平均宽度 |
| --- | ---: | ---: | ---: |
| 独立正态，零优势 | 0.001474 | 0.001510 | 0.001542 |
| 正相关，零优势 | 0.002436 | 0.002615 | 0.002672 |
| 厚尾，零优势 | 0.001472 | 0.001508 | 0.001540 |
| 正相关，真实均值差 0.001 | 0.002438 | 0.002619 | 0.002675 |

正相关非零均值差情景下，单侧功效从同次线性预白化的 44.72% 降至 43.67%。校准结论限于表中的四个情景与固定参数。
