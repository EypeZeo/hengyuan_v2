# PLAN-04 多种子、可行性优先的秩选择与独立验证

## 预先固定的方案

此前有向修正独立验证为 `not_calibrated`，默认继续使用原秩。本切片**不复用此前任何设计或验证种子**，也不根据那些结果回头定向调参；只保留覆盖率、误报率和配对改善的判定合同。 [上一轮结果](PLAN_04_TAIL_ROBUST_CALIBRATION.md)

1. 设计使用四个全新的根种子 `20261206`、`20261207`、`20261208`、`20261209`，每颗每情景 150 次重复。沿用四个生成情景、365 日、12 对、7/14/28 日期望区块长度、每个长度 4,999 次抽样以及 `0.925, 0.930, …, 0.985` 的秩网格。
2. 每个情景、每个长度先筛选**可行候选**：合并 Wilson 覆盖率与误报率判定必须通过，每颗设计种子的覆盖率、误报率和三长度一致误报率点估计也必须通过。然后选择最低可行秩（最小不必要加宽）；没有候选满足全部条件时记录回退单元，不得把回退当成可行。
3. 主情景 `ar_positive_null` 的 14 日区块，可行候选还须在合并设计样本中相对原秩净增至少 1.00 个百分点。没有这种候选时，整体为 `not_calibrated`。
4. 选定后冻结，使用两颗新的独立种子 `20261210`、`20261211`，每颗每情景 400 次重复。验证数据不参与选秩；若需再改方案，必须另起实验并使用新的独立种子。

## 判定标准

- 合并数据按上一轮标准：每个情景、每个长度的同时覆盖率，其逐项 95% Wilson 区间整体位于 92% 至 98%；每个长度及三种长度一致判定的误报率，其逐项 95% Wilson 区间上界不超过 7.5%。
- 每颗验证种子分别用点估计检查同样的覆盖率和误报率容差，两颗均须通过。
- 主情景的配对覆盖改善标准沿用上一轮：原秩与本轮新秩比较，净增至少 1.00 个百分点，且不一致结果中新秩覆盖占比的 Wilson 下界超过 50%。
- 设计约束、任一回退单元、任一验证标准未满足，或任一估计失败时，状态为 `not_calibrated`。Smoke 只验证流程，不用于宣称校准通过。
