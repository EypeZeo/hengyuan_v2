# PLAN-04 尾部收益差区间校准

## 预先固定的方案

使用既有最差 5% 日收益均值的配对平稳区块区间。每次模拟有 365 日、12 对，每个区块长度各抽样 4,999 次。长度按 7、14、28 日顺序执行，14 日为主结果。沿用每次共用日期索引和最大绝对偏差的第 4,750 个次序统计量。三种区块长度均严格排除零且方向一致时才报告稳定方向。 [既有尾部复核方案](PLAN_04_PAIRED_TAIL.md)

独立模拟种子为 `20261128`。四种情景各运行 400 次。按下表顺序为各情景分别分出随机流，再为每次外层重复分出随机流。每次重复分别用独立 PCG64 随机流生成收益和三种区块抽样。每次重复的种子由情景和重复次序确定。

令标准化高斯创新为 `sqrt(0.3)×F[t] + sqrt(0.3)×G[t,pair] + sqrt(0.4)×E[t,pair,side]`。三组因子相互独立，各自为独立标准正态。该式产生 0.6 的同期配对相关和 0.3 的同期跨配对相关。下表各情景的边际标准差均为 1%。正相关情景使用平稳初始化的 AR(1)，系数为 0.5。厚尾情景按日期共用独立的 `sqrt(3/χ²(5))` 因子，使边际成为标准差为 1% 的 Student t(5)。

| 情景 | 收益生成 | 各对真实尾部均值差 |
| --- | --- | --- |
| 独立日期正态零差异 | 同期相关高斯创新，日期之间独立 | 全为 0 |
| 正自相关正态零差异 | AR(1) 高斯路径 | 全为 0 |
| 厚尾零差异 | 独立日期 Student t(5)，同日共用尺度 | 全为 0 |
| 正自相关混合差异 | AR(1) 高斯路径，前六对候选收益平移 −0.006 | 前六对 −0.006，后六对 0 |

真值取候选边际尾部均值减去参照边际尾部均值。相同边际给出零差异，固定平移使尾部均值同幅变化。

## 判定标准

- 每种区块长度的同时覆盖指该重复的全部 12 个真值均包含在区间内。每个情景、每种长度的覆盖率，其逐项 95% Wilson 区间必须整体位于 92% 至 98%。
- 误报指至少一个真值为零的比较被报告为严格偏离零。分别计算各长度的误报率，以及三种长度一致方向判定的误报率。四种情景的各项逐项 95% Wilson 区间上界均须不超过 7.5%。
- 混合差异情景另报告至少检出一项真实负差异的比例及六项全部检出的比例。功效和平均半宽作为描述结果。
- 估计失败保留计数。任一估计失败或必需标准未满足时，总状态为 `not_calibrated`。此方案覆盖所列合成情景和既定样本规模。 [Wilson 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
