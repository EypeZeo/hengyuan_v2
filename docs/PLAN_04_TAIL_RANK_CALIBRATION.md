# PLAN-04 尾部区间固定秩调整

## 预先固定的改进方案

沿用前一轮的四个生成情景、已知真值、365 日、12 对、7/14/28 日期望区块长度和每种长度 4,999 次抽样。14 日仍为主结果。比较时，两种方法使用同一条模拟路径和同一组区块索引。 [上一轮校准方案](PLAN_04_TAIL_COVERAGE.md)

两种方法均以原样本尾部收益差为中心，以区块抽样中 12 对最大绝对偏差的某个次序统计量为共同半宽。原方法取 `ceil((B+1)×0.95)`，新方法固定取 `ceil((B+1)×0.965)`。在 `B=4,999` 时分别为第 4,750 和 4,825 项。提高次序可加宽区间，覆盖率和误报率仍由独立模拟判断。三种区块长度均严格排除零且方向一致时，才报告稳定方向。

新独立种子为 `20261129`，四个情景各 600 次外层重复。按既有情景顺序派生子种子，并按每次重复分开数据流和抽样流。三种区块长度分别使用独立 PCG64 流。调度顺序和进程数不改变随机流。

## 判定标准

- 新方法的每种情景、每种区块长度的同时覆盖率，其逐项 95% Wilson 区间必须整体位于 92% 至 98%。各长度及三种长度一致判定的误报率，其逐项 95% Wilson 区间上界均须不超过 7.5%。
- 正自相关零差异情景的 14 日新方法，相对同次原方法的同时覆盖率须净增至少 1.00 个百分点。在两者覆盖结果不同的重复中，新方法覆盖占比的逐项 95% Wilson 区间下界须高于 50%。
- 记录两种方法的平均半宽及混合差异情景的至少一项和全部六项检出率。功效仅作描述。
- 任一估计失败或任一必需标准未满足时，总状态为 `not_calibrated`。结论以本次固定的秩、样本长度和合成情景为限。 [Wilson 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
