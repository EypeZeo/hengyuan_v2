# PLAN-05 配对区块抽样与校准

## 统计方法

输入为按期对齐的完整净收益矩阵，包括空仓期。第一列为参照，后续各列为冻结候选。每次抽样从均匀随机行开始，之后每一步以 `1/L` 的概率随机选择新起点，否则沿原序列向后取一行，末行之后循环至首行。所有列共用同一组索引。`L` 为预先固定的期望区块长度。 [Politis–Romano](https://statistics.stanford.edu/technical-reports/stationary-bootstrap)

- **固定候选比较。** 以候选减参照的单期平均差为估计值。同步抽取逐期差额，以重采样均值误差的分位数构造双侧基本 bootstrap 区间及单侧下限。
- **固定候选选择。** 观测统计量为各候选平均超额收益的最大值。将每列差额减去该列样本均值，在联合零假设下同步抽样，每次重新计算全部候选的最大均值。以至少达到观测最大值的抽样次数加一，除以抽样次数加一，得到近似 p 值。列顺序决定并列胜者。

该选择试验的结论限于固定候选集合和联合零优势假设。含重新训练、阈值重估与动态选模的流程需要在各自的训练窗口重做。 [研究执行计划 §6.5](RESEARCH_EXECUTION_PLAN.md#65-配对区块自助法)

## 固定模拟方案

每个情景使用 512 期，每期边际收益标准差为 1%。期望区块长度为 16，每次重复抽取 399 个 bootstrap 样本。六个情景各独立重复 2,000 次。种子为 `20261121`，用 NumPy PCG64 分别生成原始序列和重采样索引。高斯 AR(1) 从平稳分布初始化。

| 情景 | 跨期相关 | 候选相关或配对相关 | 真实单期均值差 |
| --- | --- | --- | ---: |
| 单一正态候选与参照 | 独立 | 配对 0.6 | 0 |
| 单一高斯 AR(1) 候选与参照 | `φ=0.5` | 配对 0.6 | 0 |
| 单一厚尾候选与参照 | 独立 | 以标准化独立 Student t(5) 成分实现配对相关 0.6 | 0 |
| 单一高斯 AR(1) 候选与参照 | `φ=0.5` | 配对 0.6 | 0.001 |
| 六个高斯候选与独立参照 | 独立 | 候选间独立 | 0 |
| 六个高斯 AR(1) 候选与独立参照 | `φ=0.5` | 候选间同期相关 0.6 | 0 |

固定集合表中的相关系数对应原始候选列。由于各超额收益列减去同一个独立参照，这两种集合的超额收益列同期相关分别为 0.5 和 0.8。

单一候选评估双侧 95% 覆盖率与单侧 5% 拒绝率。固定集合评估联合零假设下的 5% 拒绝率。采用逐项 95% Wilson 区间，覆盖率容差 92%–98%，误报率上限 7.5%。非零均值差情景的拒绝率作为功效描述。正式总状态要求各必需指标的区间完全落入各自容差且无估计失败。 [Wilson 区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

在仓库根目录运行。JSON 记录观察长度、重复次数、区块与抽样设置和各情景结果。`--smoke` 运行 12 次、每次抽样 39 次，用于检查入口。

```powershell
python -B -m py_core.tools.calibrate_paired_bootstrap
```

## 离线校准结果

2026-11-18 使用 NumPy 2.5.1 完成 12,000 次模拟，每次抽样 399 次，无估计失败。使用相同种子和参数复跑，完整 JSON 报告一致。正式总状态为 **`not_calibrated`**。

| 情景 | 覆盖率及 Wilson 区间 | 单侧拒绝率或联合误报率及 Wilson 区间 |
| --- | --- | --- |
| 正态配对，零优势 | 93.90% [92.76%, 94.87%] | 5.75% [4.81%, 6.86%] |
| AR(1) 配对，零优势 | 90.50% [89.14%, 91.71%] | 7.30% [6.24%, 8.52%] |
| 厚尾配对，零优势 | 92.80% [91.58%, 93.85%] | 6.20% [5.22%, 7.34%] |
| AR(1) 配对，均值差 0.001 | 91.40% [90.09%, 92.55%] | 48.45% [46.26%, 50.64%] |
| 独立原始候选，联合零优势 | — | 5.60% [4.67%, 6.70%] |
| 相关 AR(1) 原始候选，联合零优势 | — | 6.15% [5.18%, 7.29%] |

正态配对和两个固定集合满足各自预设容差。AR(1) 零优势的配对覆盖率区间整体低于 92% 下限，单侧误报区间跨过 7.5% 上限。厚尾配对和 AR(1) 非零均值差的覆盖率区间也跨过 92% 下限。使用该观察长度与区块长度时，配对基本区间尚不足以支持统一的研究准入判断。
