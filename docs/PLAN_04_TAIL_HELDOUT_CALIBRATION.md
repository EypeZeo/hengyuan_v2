# PLAN-04 尾部区间选秩与独立验证

## 预先固定的方案

统一秩在两轮独立厚尾样本上的 28 日同时覆盖率分别为 563/600 和 782/800。用一组新模拟选秩，再用两组独立模拟复核，检验每个区块长度能否用同一秩满足四个情景的覆盖率和误报率标准。 [统一秩校准](PLAN_04_TAIL_RANK_CALIBRATION.md) [分长度校准](PLAN_04_TAIL_LENGTH_CALIBRATION.md)

沿用四个生成情景、已知真值、365 日、12 对、7/14/28 日期望区块长度和每种长度 4,999 次抽样。不同方法在同一重复内共享数据和抽样索引。选秩种子为 `20261201`，每个情景 300 次重复。验证种子固定为 `20261202` 和 `20261203`，每个种子每个情景各 400 次重复。三个根种子各自派生情景、重复、数据和区块抽样的 PCG64 随机流。

1. 在 `0.925, 0.930, …, 0.985` 的网格上，逐个长度计算四个情景的同时覆盖率。每个长度选取使四个情景覆盖率与 95.5% 目标之间最大绝对距离最小的水平。距离相同时取较低水平。抽样秩为 `ceil((B+1)×p)`。
2. 14 日候选还须在选秩样本的正自相关零差异情景中，相对同次原秩净增至少 1.00 个百分点。若无候选满足该条件，仍按最小距离规则记录诊断候选，整体判为 `not_calibrated`。选秩样本任一估计失败时结束本次校准。
3. 冻结三个选定的水平后运行两个验证种子。比较原秩、统一调整、预先固定的分长度调整和本轮选定的秩。两组验证各自报告，并在每个情景内合并计数后给出判定。

## 验证标准

- 合并后的数据按上一轮标准判定。四个情景每个长度的同时覆盖率，其逐项 95% Wilson 区间须整体位于 92% 至 98%。每个长度和三种长度一致判定的误报率，其逐项 95% Wilson 区间上界须不超过 7.5%。 [Wilson 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
- 每个验证种子单独检查同样的覆盖率与误报率容差，使用点估计。两组均须通过。
- 在合并的正自相关零差异情景中，14 日覆盖率相对同次原秩须净增至少 1.00 个百分点。在覆盖结果不同的重复中，新方法覆盖占比的 95% Wilson 区间下界须超过 50%。
- 选秩约束或任一验证标准未满足，或任一验证估计失败时，状态为 `not_calibrated`。报告 28 日误报率及区间、平均半宽、混合差异情景中三种长度一致判定至少检出一项和全部六项真实差异的比例。半宽、检出率和相对上一轮方法的误报率变化用于描述。
