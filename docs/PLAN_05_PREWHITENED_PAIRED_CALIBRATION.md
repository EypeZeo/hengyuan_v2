# PLAN-05 预白化学生化配对区间校准

## 预先固定的方案

采用 AR(1) 预白化，检验正相关情景中由有限带宽造成的标准误偏差能否进一步减小。原始差额序列与每个重采样序列分别减去自己的样本均值。以相邻期的无截距最小二乘拟合 `φ`，对 `n−1` 个残差估计带宽 8 的 Bartlett 长期方差 `Ωε`，再用 `sqrt(Ωε/n) / |1−φ|` 得到原尺度的均值标准误。拟合分母为零或非有限、`|φ| ≥ 1`、标准误非正或非有限均记录为估计失败。基本区间和改进区间共用原始序列及每次重采样的行索引。学生化枢轴及分位数规则沿用上一轮。 [Andrews–Monahan 预白化方法](https://cowles.yale.edu/node/145654) · [上一轮学生化配对区间](PLAN_05_STUDENTIZED_PAIRED_CALIBRATION.md)

使用独立种子 `20261123`，每个情景 6,000 次模拟，每次 399 个重采样，期望区块长度 16。沿用 512 期、同期配对相关 0.6、边际标准差 1% 的四个情景。主情景为高斯 AR(1) 系数 0.5 且真实均值差为零。其余情景为独立正态零优势、厚尾零优势、AR(1) 系数 0.5 且真实均值差为 0.001。增加模拟次数用于缩小蒙特卡洛误差。

## 判定标准

- 四个情景的双侧 95% 覆盖率均须以逐项 95% Wilson 区间整体落入 92%–98%。
- 三个零优势情景的单侧 5% 误报率均须以逐项 95% Wilson 区间上界不超过 7.5%。非零均值差的检验功效和平均区间宽度作为描述结果。
- 相对于同一轮基本区间，主情景覆盖率须净增至少 2 个百分点。在仅一种方法覆盖的重复中，改进区间覆盖占比的 95% Wilson 区间下界须高于 50%。
- 任一估计失败或必需条件未满足时，总状态为 `not_calibrated`。
