# PLAN-05 预白化学生化配对区间校准

## 预先固定的方案

采用 AR(1) 预白化，检验正相关情景中由有限带宽造成的标准误偏差能否进一步减小。原始差额序列与每个重采样序列分别减去自己的样本均值。以相邻期的无截距最小二乘拟合 `φ`，对 `n−1` 个去均值残差估计带宽 8 的 Bartlett 长期方差 `Ωε`，再用 `sqrt(Ωε/n) / |1−φ|` 得到原尺度的均值标准误。拟合分母为零或非有限、`|φ| ≥ 1`、标准误非正或非有限均记录为估计失败。基本区间和改进区间共用原始序列及每次重采样的行索引。学生化枢轴及分位数规则沿用上一轮。 [Andrews–Monahan 预白化方法](https://cowles.yale.edu/node/145654) · [上一轮学生化配对区间](PLAN_05_STUDENTIZED_PAIRED_CALIBRATION.md)

使用独立种子 `20261123`，每个情景 6,000 次模拟，每次 399 个重采样，期望区块长度 16。沿用 512 期、同期配对相关 0.6、边际标准差 1% 的四个情景。主情景为高斯 AR(1) 系数 0.5 且真实均值差为零。其余情景为独立正态零优势、厚尾零优势、AR(1) 系数 0.5 且真实均值差为 0.001。增加模拟次数用于缩小蒙特卡洛误差。

## 判定标准

- 四个情景的双侧 95% 覆盖率均须以逐项 95% Wilson 区间整体落入 92%–98%。
- 三个零优势情景的单侧 5% 误报率均须以逐项 95% Wilson 区间上界不超过 7.5%。非零均值差的检验功效和平均区间宽度作为描述结果。
- 相对于同一轮基本区间，主情景覆盖率点估计须净增至少 2 个百分点。在仅一种方法覆盖的重复中，改进区间覆盖占比的 95% Wilson 区间下界须高于 50%。
- 任一估计失败或必需条件未满足时，总状态为 `not_calibrated`。

## 复现命令

从仓库根目录运行。JSON 报告包含两种方法的覆盖计数、拒绝计数、平均区间宽度、配对覆盖差和各项判定。`--smoke` 用于检查入口。

```powershell
python -B -m py_core.tools.calibrate_paired_studentized --prewhiten
```

## 独立验证结果

2026-11-18 使用 NumPy 2.5.1 完成 24,000 次模拟，两种方法各有 24,000 个有效估计。总状态为 **`not_calibrated`**。

| 情景 | 基本区间覆盖率 | 预白化学生化区间覆盖率 | 预白化学生化单侧拒绝率 | 平均区间宽度，基本 / 预白化 |
| --- | --- | --- | --- | --- |
| 独立正态，零优势 | 92.87% [92.19%, 93.49%] | 93.35% [92.69%, 93.95%] | 6.55% [5.95%, 7.20%] | 0.001473 / 0.001509 |
| 正相关，零优势 | 91.95% [91.23%, 92.61%] | 93.92% [93.28%, 94.49%] | 5.07% [4.54%, 5.65%] | 0.002438 / 0.002618 |
| 厚尾，零优势 | 92.93% [92.26%, 93.55%] | 93.50% [92.85%, 94.10%] | 6.63% [6.03%, 7.29%] | 0.001467 / 0.001503 |
| 正相关，真实均值差 0.001 | 91.63% [90.91%, 92.31%] | 93.23% [92.57%, 93.84%] | 44.62% [43.36%, 45.88%] | 0.002433 / 0.002611 |

四个情景的覆盖率和三个零优势情景的误报率满足容差。主情景的配对覆盖结果有 122 次仅预白化区间覆盖，4 次仅基本区间覆盖。预白化区间占不一致结果的 96.83% [92.12%, 98.76%]，方向条件满足。覆盖次数净增 118 次，增幅 1.97 个百分点，低于 120 次所对应的 2 个百分点。

正相关非零均值差情景的单侧功效从基本区间的 48.85% 降至 44.62%。本轮结论适用于表中四个情景和预先固定的参数。
