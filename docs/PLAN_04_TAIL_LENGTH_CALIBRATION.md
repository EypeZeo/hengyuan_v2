# PLAN-04 按区块长度校准尾部区间

## 预先固定的方案

使用同一组平稳区块抽样的最大绝对偏差次序统计量，比较原秩、上一轮的统一调整秩与本轮的分长度调整秩。三种方法共享每次模拟的 365 日、12 对收益和每个长度的 4,999 组抽样索引，区间均以原样本尾部收益差为中心。沿用上一轮四个情景和已知真值。 [上一轮校准](PLAN_04_TAIL_RANK_CALIBRATION.md) [平稳区块抽样](https://doi.org/10.1080/01621459.1994.10476870)

| 期望区块长度 | 原方法 | 统一调整 | 分长度调整 |
| --- | ---: | ---: | ---: |
| 7 日 | 4,750 | 4,825 | 4,800 |
| 14 日 | 4,750 | 4,825 | 4,825 |
| 28 日 | 4,750 | 4,825 | 4,900 |

秩为 `ceil((B+1)×p)`，其中 `B` 为抽样次数。分长度调整的三个 `p` 固定为 `0.960`、`0.965`、`0.980`，对所有情景使用同一组值。上一轮厚尾情景的 7 日覆盖率区间上界超过容差，28 日覆盖率区间下界低于容差。较短区块的调整略微收窄区间，较长区块的调整加宽区间，以检验同时改善厚尾覆盖率与 28 日误报率的可能性。

独立种子固定为 `20261130`。每个情景 800 次外层重复，共 3,200 次，增加重复次数以缩小比例区间的抽样误差。按情景和重复派生子种子，每次重复分别派生数据流和三个区块长度的 PCG64 抽样流。运行前固定三个秩、种子和样本数，完成全部重复后判定。

## 判定标准

1. 分长度调整在四个情景、三种长度的同时覆盖率，其逐项 95% Wilson 区间须整体位于 92% 至 98%。每种长度和三种长度一致判定的误报率，其逐项 95% Wilson 区间上界均须不超过 7.5%。
2. 正自相关零差异情景的 14 日同时覆盖率，相对同次原秩须净增至少 1.00 个百分点。在覆盖结果不同的重复中，分长度调整覆盖占比的 95% Wilson 区间下界须高于 50%。
3. 独立正态和厚尾两个零差异情景的 28 日误报率，各自须相对同次统一调整净降至少 1.00 个百分点，并报告两种方法的配对误报计数。
4. 任一估计失败或上述任一条件未满足时，总状态为 `not_calibrated`。报告三种方法的平均半宽，以及混合差异情景中三种长度一致判定至少检出一项和全部六项真实差异的比例。检出率用于描述。 [Wilson 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)
