# PLAN-05 重新训练与动态选模校准

## 预先固定的流程

使用 512 期合成数据，包含六列在当期收益实现前可见的预测量和一列市场收益。参照为空仓，模拟交易成本设为零。每个候选用一列预测量对收益做过原点的一元最小二乘拟合。预测值严格大于零时持有一单位，其余时候空仓。训练窗内预测量平方和为零时，拟合系数设为零。

每折使用距测试窗最近的 96 期训练所有候选，在紧接的 32 期验证窗按平均收益选出胜者，平手取列号最小者。随后用这 128 期重新拟合胜者，在接下来的 32 期测试窗评估。每次向前滚动 32 期，已实现的历史测试收益可进入后续折的拟合。本方案共拼接 12 个互不重叠的样本外测试窗，统计量为这 384 期相对空仓的平均收益。 [滚动时间序列验证](https://otexts.robjhyndman.com/fpp3/tscv.html)

## 零假设与模拟设计

零假设要求在给定全部预测量与收益绝对值后，各期收益符号相互独立且等概率取正负。每次对全部 512 期收益独立随机化符号，保留绝对值及预测量的原时序。每条随机化路径都重新执行训练、验证选择、拟合和样本外评估。原路径加 199 条随机化路径，单侧 p 值为 `(1 + 随机化统计量不小于原统计量的次数) / 200`。该条件零假设适用于本方案生成的数据。 [含原路径的随机化检验](https://pmc.ncbi.nlm.nih.gov/articles/PMC6405018/)

外层采用独立种子 `20261125`，四个情景各 2,400 次。PCG64 为不同情景及原始数据与随机符号分别派生随机流。基础收益创新标准差为 1%。相关预测量使用同期相关 0.6 的高斯创新并从平稳 AR(1) 初始化，系数为 0.5。

| 情景 | 六列预测量 | 市场收益 |
| --- | --- | --- |
| 独立正态零优势 | 跨期、跨列独立正态 | 独立正态 |
| 相关预测量与波动变化 | 上述相关 AR(1) | 独立正态创新，标准差按每 64 期在基础值的 0.5 与 1.5 倍之间交替 |
| 厚尾零优势 | 上述相关 AR(1) | 独立 Student t(5) 创新，缩放为 1% 标准差 |
| 有优势且信号切换 | 上述相关 AR(1) | 正态创新加 `0.006 × x`。前 256 期使用第一列，后 256 期使用第二列 |

## 判定标准

- 以 `p ≤ 0.05` 计为拒绝。三个零优势情景各自的误报率 95% Wilson 区间上界须不超过 7.5%。
- 有优势且信号切换情景的功效 95% Wilson 区间下界须至少为 70%。记录每种情景至少切换一次候选的比例及平均切换次数，用于核查选择过程确实随时间变化。
- 任一估计失败或必需条件未满足时，总状态为 `not_calibrated`。报告保留估计失败数与有效重复数。 [Wilson 区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

## 复现命令

在仓库根目录运行。正式 JSON 报告包含随机种子、数据规模、窗长、误报率或功效、候选切换、平均样本外收益和各项判定。`--smoke` 运行 12 次，每次包含 19 条随机化路径，用于验证入口。

```powershell
python -B -m py_core.tools.calibrate_dynamic_selection
```

## 独立验证结果

2026-11-18 使用 NumPy 2.5.1 完成 9,600 次外层模拟，重跑 1,910,400 条随机化路径。所有重复均有效。使用相同种子与参数复跑，完整 JSON 一致。总状态为 **`within_tolerance`**。

| 情景 | 误报率或功效及 95% Wilson 区间 | 拒绝次数 / 有效重复 | 至少切换一次 | 平均切换次数 |
| --- | --- | ---: | ---: | ---: |
| 独立正态零优势 | 5.12% [4.31%, 6.08%] | 123 / 2,400 | 100.00% | 9.19 |
| 相关预测量与波动变化 | 5.00% [4.20%, 5.95%] | 120 / 2,400 | 100.00% | 9.22 |
| 厚尾零优势 | 5.04% [4.24%, 5.99%] | 121 / 2,400 | 100.00% | 9.15 |
| 有优势且信号切换 | 99.04% [98.57%, 99.36%] | 2,377 / 2,400 | 100.00% | 7.42 |

三个零优势情景的误报率上界均低于 7.5%，信号切换情景的功效下界高于 70%。结论适用于本方案的六候选规则、窗口和条件独立对称符号零假设。依赖历史收益符号生成的预测量，以及符号具有跨期依赖的数据，需要按各自生成方式另行校准。
