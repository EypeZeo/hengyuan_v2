# PLAN-05 离线模拟校准

## 方案 v1

对等间隔、未年化的合成收益运行现有 HAC 与 DSR 实现。每种情景固定 2,400 次独立重复，种子为 `20261118`，使用 NumPy PCG64 为各情景生成独立随机流。单期总体收益标准差为 1%，总体 Sharpe 为单期均值除以该标准差。正式运行前固定样本数、带宽、统计量与容差。

| HAC 情景 | 样本数 | Bartlett 带宽 | 总体 Sharpe |
| --- | ---: | ---: | ---: |
| 独立正态、AR(1) `φ=+0.5`、AR(1) `φ=-0.5`、独立 Student t(5) | 1,024 | 32 | 0 |
| AR(1) `φ=+0.5`、独立 Student t(5) | 1,024 | 32 | 0.05 |
| AR(1) `φ=+0.5` 短样本 | 256 | 8 | 0 |

高斯 AR(1) 从平稳分布初始化，创新项按 `sqrt(1−φ²)` 缩放。Student t(5) 按 `sqrt(3/5)` 缩放为单位方差。以双侧 95% 正态近似区间估计覆盖率，以单侧 5% 检验估计零假设误报率或非零优势下的检验功效。报告 Sharpe 的模拟标准差和平均 HAC 标准误。带宽为每行固定值。 [研究执行计划 §6.3](RESEARCH_EXECUTION_PLAN.md#63-hac-对-sharpe-的使用) · [Newey–West](https://www.nber.org/papers/t0055)

候选选择试验固定 12 列、每列 252 期、HAC 带宽 8。候选总体 Sharpe 均为 0，跨期独立，候选间同期相关分别为 0 或 0.6。每次按样本 Sharpe 选胜者，对其运行单侧 5% HAC 检验及现行 DSR `>= 0.95` 判定。分别记录两种误报率。未经选择校正的 HAC 结果只用于描述选择效应。 [研究执行计划 §6.4](RESEARCH_EXECUTION_PLAN.md#64-多重选择与-dsr)

每个比率附逐项 95% Wilson 蒙特卡洛区间。HAC 覆盖率容差为 92%–98%，零假设下 HAC 及候选胜者 DSR 的误报率上限为 7.5%。区间全部落入容差才记为 `within_tolerance`，与容差无交集记为 `outside_tolerance`，其余记为 `insufficient_evidence`。非零优势下的功效仅报告描述值。估计失败单独计数，任何失败或必需指标缺乏容差内的结果均使正式总状态为 `not_calibrated`。这些容差用于本次合成实验，现行研究准入仍采用仓库已有标准。 [NIST Wilson 区间说明](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

在仓库根目录运行。JSON 包含参数、分子和分母、区间、估计失败数和各项结果。命令以退出码 0 表示报告成功生成，读取 `status` 获取统计结论。`--smoke` 每个情景只运行 12 次，结果的总状态为 `smoke`。

```powershell
python -B -m py_core.tools.calibrate_plan05
```

## 正式运行结果

2026-11-18 使用 NumPy 2.5.1 运行了 9 个情景，每个情景 2,400 次重复，共 21,600 次。所有 HAC 和 DSR 调用均返回可用估计。正式总状态为 **`not_calibrated`**。

六个 1,024 期情景满足各自的预设容差。256 期正相关零优势情景的覆盖率区间跨过 92% 下限，误报率区间跨过 7.5% 上限，两项均为 `insufficient_evidence`。该情景的平均 HAC 标准误比 Sharpe 模拟标准差低约 11%，仍需校准。

短样本情景另用种子 `20261119` 独立复核 9,600 次，沿用 256 期、带宽 8 和同一判定范围。覆盖率为 91.74% [91.17%, 92.27%]，仍为 `insufficient_evidence`。误报率为 6.79% [6.31%, 7.31%]，满足上限。该复核单独报告，正式总状态仍为 `not_calibrated`。
